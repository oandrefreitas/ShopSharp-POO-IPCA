# ShopSharp-POO-IPCA

Projeto académico desenvolvido na unidade curricular de Programação Orientada a Objetos (POO). Consiste num sistema de gestão de loja implementado em C#, estruturado com uma arquitetura em camadas (Model, DAL e BLL). Inclui gestão de produtos, clientes, categorias, marcas, campanhas, carrinho de compras e registo de vendas, com armazenamento de dados em ficheiros JSON.

## Funcionalidades principais

* Arquitetura em camadas: Model, Data Access Layer (DAL) e Business Logic Layer (BLL).

* Gestão de produtos, categorias, marcas e garantias.

* Gestão de clientes, incluindo herança para clientes particulares e empresariais.

* Sistema de campanhas promocionais, com associação de produtos e cálculo de descontos.

* Carrinho de compras com validação de stock e cálculo de totais.

* Registo de vendas, incluindo cálculo do preço final e campanhas aplicadas.

* Persistência de dados em ficheiros JSON utilizando a biblioteca Newtonsoft.Json.

* Interface de interação em modo consola para gestor e cliente.

# ShopSharp-POO-IPCA

Academic project developed for the Object-Oriented Programming (OOP) course. It is a store management system built in C#, structured with a layered architecture (Model, DAL and BLL). Includes management of products, customers, categories, brands, campaigns, shopping cart and sales records, with data persistence handled through JSON files.

## Main Features

* Layered architecture: Model, Data Access Layer (DAL) and Business Logic Layer (BLL).

* Management of products, categories, brands and warranties.

* Customer management with inheritance for individual and business customers.

* Promotional campaign system with product associations and discount calculations.

* Shopping cart with stock validation and total price calculation.

* Sales registration with final price computation and applied campaigns.

* Data persistence using JSON files (Newtonsoft.Json).

* Console-based user interface for manager and customer.
